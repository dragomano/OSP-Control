# Падрыхтоўка Symfony

Корань праекта — гэты каталог, публічны каталог — public/.
public/index.php спачатку паказвае заглушку ўсталявання.

1. Уключыце выбраныя модулі HTTP і PHP у OSPanel.
2. У OSP Control адкрыйце **__OVERVIEW__** праекта і націсніце **__INSTALL_BUTTON__**.
3. Composer стварае праграму ў ізаляваным часовым каталогу: спачатку каркас,
   потым `composer require webapp` для поўнай вэб-праграмы (Twig, Doctrine, MakerBundle).
   У корань праекта пераносіцца толькі паспяховае ўсталяванне. Налады .osp захоўваюцца,
   а стартавы public/.htaccess застаецца для маршрутызацыі Apache. Дадатковыя файлы
   праекта ці правкі заглушкі трэба ўхіліць да ўсталявання.
4. Зыходная загатоўка захоўваецца ў backups/starters/ унутры ўсталявання OSPanel.
   Памылкі Composer не кранаюць зыходную загатоўку, усталяванне можна паўтарыць.
5. Перазапусціце OSPanel і адкрыйце сайт. Актыўуйце кансольнае асяроддзе праекта:
   `osp project __DOMAIN__`. Дадатковага каталога-абгорткі вакол src/ няма.
6. Праверце .env і базу даных патрабаванням усталяванай версіі. Усталявальнік падрыхтуе
   выбраную базу і запіша DATABASE_URL у .env. Пасля дадання ўласных міграцый выканайце
   `php bin/console doctrine:migrations:migrate`. npm не ўсталёўваецца і не запускаецца OSP Control.

Усталяванне выкарыстоўвае выбраны модуль PHP праекта (__PHP_ENGINE__) і яго актыўны
профіль Composer OSPanel. Пераканайцеся, што пашырэнні PHP адпавядаюць патрабаванням Symfony.
Усталявальнік адмовіцца перазапісваць існуючую праграму ці змененую заглушку.

https://symfony.com/doc/current/setup.html

## Налада базы даных

SQLite стварае `var/<выбраная-назва>.sqlite`, злучэнне запісваецца ў .env.
Для MySQL, MariaDB або PostgreSQL спачатку запусціце выбаны модуль OSPanel;
карыстальніку патрэбна права CREATE DATABASE. Усталявальнік адхіляе існуючыя базы
і захоўвае створаныя ім для паўторнай спробы. Рэквізіты захоўваюцца ў
`.osp/database.json` (выключана з Git) і ў `.env` праграмы. Трымайце абодва файлы ў таямніцы.
З **__CONFIGURE_LATER__** праграма ўсталёўваецца без DATABASE_URL да налады.
