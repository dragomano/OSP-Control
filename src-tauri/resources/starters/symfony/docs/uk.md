# Підготовка Symfony

Корінь проєкту — цей каталог, публічний каталог — public/.
public/index.php спочатку показує заглушку встановлення.

1. Увімкніть вибрані модулі HTTP і PHP в OSPanel.
2. У OSP Control відкрийте **__OVERVIEW__** проєкту та натисніть **__INSTALL_BUTTON__**.
3. Composer створює застосунок в ізольованому тимчасовому каталозі: спочатку каркас,
   потім `composer require webapp` для повноцінного вебзастосунку (Twig, Doctrine,
   MakerBundle). У корінь проєкту переноситься лише успішне встановлення. Налаштування .osp
   зберігаються, а стартовий public/.htaccess залишається для маршрутизації Apache.
   Додаткові файли проєкту чи правки заглушки потрібно усунути до встановлення.
4. Вихідна заготовка зберігається в backups/starters/ усередині встановлення OSPanel.
   Помилки Composer не зачіпають вихідну заготовку, встановлення можна повторити.
5. Перезапустіть OSPanel і відкрийте сайт. Активуйте консольне середовище проєкту:
   `osp project __DOMAIN__`. Додаткового каталогу-обгортки навколо src/ немає.
6. Перевірте .env і базу даних за вимогами встановленої версії. Інсталятор підготує
   вибрану базу та запише DATABASE_URL до .env. Після додавання власних міграцій виконайте
   `php bin/console doctrine:migrations:migrate`. npm не встановлюється і не запускається OSP Control.

Встановлення використовує вибраний модуль PHP проєкту (__PHP_ENGINE__) та його активний
профіль Composer OSPanel. Переконайтеся, що розширення PHP відповідають вимогам Symfony.
Інсталятор відмовиться перезаписувати наявний застосунок чи змінену заглушку.

https://symfony.com/doc/current/setup.html

## Налаштування бази даних

SQLite створює `var/<вибране-ім'я>.sqlite`, підключення записується до .env.
Для MySQL, MariaDB або PostgreSQL спочатку запустіть вибраний модуль OSPanel;
користувачеві потрібне право CREATE DATABASE. Інсталятор відхиляє наявні бази
і зберігає створені ним для повторної спроби. Реквізити зберігаються в
`.osp/database.json` (виключено з Git) та у `.env` застосунку. Тримайте обидва файли в таємниці.
З **__CONFIGURE_LATER__** застосунок встановлюється без DATABASE_URL до налаштування.
