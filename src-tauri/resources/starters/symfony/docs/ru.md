# Подготовка Symfony

Корень проекта — этот каталог, публичный каталог — public/.
public/index.php сначала показывает заглушку установки.

1. Включите выбранные модули HTTP и PHP в OSPanel.
2. В OSP Control откройте **__OVERVIEW__** проекта и нажмите **__INSTALL_BUTTON__**.
3. Composer создаёт приложение в изолированном временном каталоге: сначала каркас,
   затем `composer require webapp` для полноценного веб-приложения (Twig, Doctrine,
   MakerBundle). В корень проекта переносится только успешная установка. Настройки .osp
   сохраняются, а стартовый public/.htaccess остаётся для маршрутизации Apache.
   Дополнительные файлы проекта или правки заглушки нужно устранить до установки.
4. Исходная заготовка сохраняется в backups/starters/ внутри установки OSPanel.
   Ошибки Composer не трогают исходную заготовку, установку можно повторить.
5. Перезапустите OSPanel и откройте сайт. Активируйте консольное окружение проекта:
   `osp project __DOMAIN__`. Дополнительного каталога-обёртки вокруг src/ нет.
6. Проверьте .env и базу данных по требованиям установленной версии. Установщик
   подготовит выбранную базу и запишет DATABASE_URL в .env. После добавления собственных
   миграций выполните `php bin/console doctrine:migrations:migrate`. npm не устанавливается
   и не запускается OSP Control.

Установка использует выбранный модуль PHP проекта (__PHP_ENGINE__) и его активный
профиль Composer OSPanel. Убедитесь, что расширения PHP соответствуют требованиям Symfony.
Установщик откажется перезаписывать существующее приложение или изменённую заглушку.

https://symfony.com/doc/current/setup.html

## Настройка базы данных

SQLite создаёт `var/<выбранное-имя>.sqlite`, подключение записывается в .env.
Для MySQL, MariaDB или PostgreSQL сначала запустите выбранный модуль OSPanel;
пользователю нужно право CREATE DATABASE. Установщик отклоняет существующие базы
и сохраняет созданные им для повторной попытки. Реквизиты хранятся в
`.osp/database.json` (исключён из Git) и в `.env` приложения. Держите оба файла в тайне.
С **__CONFIGURE_LATER__** приложение устанавливается без DATABASE_URL до настройки.
