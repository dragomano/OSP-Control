# Заготовка проекта SMF

Корень проекта — `{base_dir}`; OSPanel обслуживает только `public/`.

1. Сохраните настройки проекта, затем выберите **__INSTALL_BUTTON__** во вкладке **__OVERVIEW__** проекта.
2. Установщик загрузит последнюю сборку SMF 2.1 из ночного источника сообщества,
   проверит архив и распакует файлы SMF прямо в `public/`. При этом сохранятся
   `.osp` и `gitignore` заготовки.
3. Если при создании проекта выбрана база данных, модуль MySQL/MariaDB/PostgreSQL
   должен быть запущен до установки, а учётная запись — иметь право CREATE DATABASE.
   Существующие базы с выбранным именем никогда не перезаписываются. Само
   подключение настраивается в мастере установки SMF.
4. Перезапустите OSPanel и откройте сайт. Мастер установки SMF запросит язык
   форума, подключение к базе данных и учётную запись администратора. В мастере
   доступны только те языки, чьи пакеты уже распакованы в каталог установки;
   в этот пакет входит английский, поэтому установка выполняется на английском.
   Остальные языки скачиваются позже из админ-панели форума (Languages), где также
   можно сменить язык по умолчанию. Языковые пакеты доступны по адресу
   https://download.simplemachines.org/index.php?languages. Пароль администратора
   не генерируется.

Исходная заготовка сохраняется в `backups/starters`.
При сбое загрузки или распаковки проект остаётся нетронутым. Лишние файлы или
правки этой заглушки в public/ не дадут заменить её; в этом случае используйте
новую заготовку или установите вручную. База данных, уже созданная установщиком,
сохраняется для повторной попытки.

Учётные данные базы хранятся локально в `.osp/database.json` (игнорируется Git),
а форум записывает свои настройки в `public/Settings.php`. Не публикуйте этот файл
при передаче проекта. Не делайте корень проекта публичным каталогом.
