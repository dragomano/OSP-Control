# Каркас праекта 1С-Бітрыкс

1. Перазапусціце OSPanel, каб панэль выявіла __DOMAIN__.
2. Уключыце выбраныя модулі HTTP, PHP (__PHP_ENGINE__) і MySQL/MariaDB.
3. Спампуйце `bitrixsetup.php` (новае ўсталяванне) або `restore.php` (разгортванне рэзервовай копіі) у `public/` і выдаліце стартавы `public/index.php` пры запыце ўсталёўшчыка.
4. Адкрыйце `http://__DOMAIN__/bitrixsetup.php` у браўзеры і ўкажыце параметры падключэння да базы даных.

Параметры PHP для 1С-Бітрыкс зададзеныя ў `public/.user.ini`, а правілы ЧПУ для Nginx, Apache і Caddy захаваныя ў `.osp/` і `public/.htaccess`.

Дзе ўзяць скрыпты:

- `bitrixsetup.php` — афіцыйны ўсталявальны скрыпт «1С-Бітрыкс: Кіраванне сайтам». Спампуйце яго з сайта пастаўшчыка: https://www.1c-bitrix.ru/download/ (руская рэдакцыя) або https://www.bitrixsoft.com/ (міжнародная). Прабную ліцэнзію выбіраюць у майстры ўсталявання.
- `restore.php` — афіцыйны скрыпт разгортвання сайта з рэзервовай копіі 1С-Бітрыкс. Ён прапануецца разам з копіяй, створанай у адміністрацыйнай панэлі сайта, або спампоўваецца з той жа старонкі пастаўшчыка.
