# Каркас проєкту 1С-Бітрікс

1. Перезапустіть OSPanel, щоб панель виявила __DOMAIN__.
2. Увімкніть вибрані модулі HTTP, PHP (__PHP_ENGINE__) і MySQL/MariaDB.
3. Завантажте `bitrixsetup.php` (нова установка) або `restore.php` (розгортання резервної копії) до `public/` і видаліть стартовий `public/index.php` на запит інсталятора.
4. Відкрийте `http://__DOMAIN__/bitrixsetup.php` у браузері та вкажіть параметри підключення до бази даних.

Параметри PHP для 1С-Бітрікс задано в `public/.user.ini`, а правила ЧПУ для Nginx, Apache і Caddy збережено в `.osp/` і `public/.htaccess`.

Де взяти скрипти:

- `bitrixsetup.php` — офіційний установний скрипт «1С-Бітрікс: Керування сайтом». Завантажте його з сайту постачальника: https://www.1c-bitrix.ru/download/ (російська редакція) або https://www.bitrixsoft.com/ (міжнародна). Пробну ліцензію вибирають у майстерні встановлення.
- `restore.php` — офіційний скрипт розгортання сайту з резервної копії 1С-Бітрікс. Він пропонується разом із копією, створеною в адміністративній панелі сайту, або завантажується з тієї ж сторінки постачальника.
