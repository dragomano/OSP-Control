# Каркас проекта 1С-Битрикс

1. Перезапустите OSPanel, чтобы панель обнаружила __DOMAIN__.
2. Включите выбранные модули HTTP, PHP (__PHP_ENGINE__) и MySQL/MariaDB.
3. Загрузите `bitrixsetup.php` (новая установка) или `restore.php` (развёртывание резервной копии) в `public/` и удалите стартовый `public/index.php` при запросе установщика.
4. Откройте `http://__DOMAIN__/bitrixsetup.php` в браузере и укажите параметры подключения к базе данных.

Параметры PHP для 1С-Битрикс заданы в `public/.user.ini`, а правила ЧПУ для Nginx, Apache и Caddy сохранены в `.osp/` и `public/.htaccess`.

Где взять скрипты:

- `bitrixsetup.php` — официальный установочный скрипт «1С-Битрикс: Управление сайтом». Скачайте его с сайта вендора: https://www.1c-bitrix.ru/download/ (русская редакция) или https://www.bitrixsoft.com/ (международная). Пробная лицензия выбирается в мастере установки.
- `restore.php` — официальный скрипт развёртывания сайта из резервной копии 1С-Битрикс. Он предлагается вместе с копией, созданной в административной панели сайта, или скачивается с той же страницы вендора.
