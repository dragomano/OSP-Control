# Sitio estático local

1. Reinicia OSPanel para que detecte __DOMAIN__.
2. Activa el módulo HTTP seleccionado desde OSPanel u OSP Control.
3. Abre el proyecto en el navegador.
4. Edita public/index.html y public/styles.css. Guarda los archivos privados fuera de public/.

La configuración del proyecto está en .osp/project.ini. No se modificó la configuración global de los módulos.
