# Заготовка проєкту WordPress

Корінь проєкту — `{base_dir}`; OSPanel публікує лише `public/`.

1. Збережіть налаштування проєкту й натисніть **__INSTALL_WORDPRESS__** на вкладці **__OVERVIEW__** проєкту.
2. Встановлювач завантажить офіційний стабільний ZIP-архів, перевірить його контрольну суму
   й розпакує файли WordPress безпосередньо в `public/`, зберігши `.osp` і `.htaccess`.
3. Якщо під час створення проєкту вибрано БД, заздалегідь запустіть відповідний модуль
   MySQL/MariaDB. Указаному користувачу потрібне право CREATE DATABASE.
   Наявні бази з вибраним ім’ям не перезаписуються. Параметри з’єднання
   записуються в `public/wp-config.php`; якщо БД не вибрано, налаштуйте її в майстрі в браузері.
4. Перезапустіть OSPanel і відкрийте сайт. У майстрі WordPress задайте назву сайту,
   обліковий запис адміністратора й мову. Пароль адміністратора автоматично не створюється.

Початкова заготовка зберігається в `backups/project-starters`.
За помилки завантаження або розпакування проєкт залишається незмінним. Додаткові файли
або зміни публічної заглушки блокують заміну; у такому разі створіть нову заготовку
або встановіть застосунок вручну. Створена встановлювачем база зберігається для повторної спроби.

Реквізити БД зберігаються локально в `.osp/database.json` (виключено з Git).
Не публікуйте цей файл і створений `wp-config.php`, передаючи проєкт.
Не використовуйте корінь проєкту як публічний каталог.
