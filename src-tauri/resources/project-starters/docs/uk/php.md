# Локальний PHP-застосунок

1. Перезапустіть OSPanel, щоб панель виявила __DOMAIN__.
2. Увімкніть вибрані модулі HTTP і PHP.
3. Відкрийте проєкт у браузері, а потім замініть public/index.php своїм застосунком.
4. У командному рядку OSPanel виконайте `osp project __DOMAIN__`, щоб активувати PHP-оточення проєкту.

Публічний каталог — public/. Зберігайте залежності, реквізити доступу й інші приватні файли поза ним.
Налаштування проєкту розташовані в .osp/project.ini. Пакети не встановлювалися.
