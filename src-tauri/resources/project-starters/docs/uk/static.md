# Локальний статичний сайт

1. Перезапустіть OSPanel, щоб панель виявила __DOMAIN__.
2. Увімкніть вибраний HTTP-модуль через OSPanel або OSP Control.
3. Відкрийте проєкт у браузері.
4. Редагуйте public/index.html і public/styles.css. Зберігайте приватні файли поза public/.

Налаштування проєкту розташовані в .osp/project.ini. Глобальні налаштування модулів не змінені.
