# Локальний Node.js-застосунок

1. За потреби встановіть вибрану версію Node.js через доповнення NVM в OSPanel.
   Перезапустіть OSPanel і ввімкніть вибраний HTTP-модуль.
2. У командному рядку OSPanel виконайте `osp project __DOMAIN__ start`.
3. Відкрийте проєкт у браузері. HTTP-модуль пересилає запити на 127.0.0.1:__PORT__.

Приклад сервера використовує вбудовані модулі Node.js і не потребує встановлення пакетів npm.
Команда запуску — `node server.mjs`. Також можна виконати `npm start` в оточенні проєкту.
Якщо порт __PORT__ зайнятий, виберіть інший порт backend і змініть константу порту в server.mjs.

Заготовка містить необов’язкове завдання одноразового запуску, яке спочатку вимкнене.
Увімкніть його на вкладці **__TASKS__** проєкту, якщо застосунок має запускатися разом з OSPanel.
Під час створення заготовки процеси автоматично не запускалися.
