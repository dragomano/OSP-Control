# Заготовка Laravel

Корінь проєкту — цей каталог, публічний каталог — public/.
Файл public/index.php спочатку показує заглушку встановлення.

1. Увімкніть вибрані модулі HTTP і PHP в OSPanel.
2. В OSP Control відкрийте **__OVERVIEW__** проєкту й натисніть **__INSTALL_LARAVEL__**.
3. Composer створить застосунок в окремому тимчасовому каталозі. Лише успішне встановлення
   переноситься в корінь проєкту. Налаштування .osp зберігаються.
   Додаткові файли проєкту або зміни заглушки потрібно усунути перед встановленням.
4. Початкова заготовка зберігається в backups/project-starters/ у каталозі OSPanel.
   За помилки Composer заготовка залишається незмінною; встановлення можна повторити.
5. Перезапустіть OSPanel і відкрийте сайт. Активуйте консольне оточення командою
   `osp project __DOMAIN__`. Додаткової папки навколо каталогу app/ Laravel немає.
6. Перевірте .env і параметри БД відповідно до вимог установленої версії.
   Встановлювач готує вибрану базу, виконує автовиявлення пакетів,
   створює ключ застосунку й виконує міграції. OSP Control не встановлює й не запускає npm.
7. За потреби після встановлення ввімкніть планувальник Laravel на вкладці **__TASKS__** проєкту.

Встановлення використовує вибраний PHP-модуль проєкту (__PHP_ENGINE__) та його активний
профіль Composer в OSPanel. Переконайтеся, що розширення PHP відповідають вимогам Laravel.
Встановлювач відмовиться перезаписувати наявний застосунок або змінену заглушку.

https://laravel.com/docs/installation

## Налаштування бази даних

SQLite створює `database/<selected-name>.sqlite` і виконує міграції без окремого
сервера БД. Для MySQL, MariaDB або PostgreSQL заздалегідь запустіть вибраний модуль OSPanel;
указаному користувачу потрібне право CREATE DATABASE. Встановлювач відмовляється
використовувати наявні бази й зберігає створену ним базу для повторної спроби.
Реквізити зберігаються в `.osp/database.json` (виключено з Git) і в `.env` застосунку.
Не публікуйте ці файли. Якщо вибрано **__CONFIGURE_LATER__**, міграції пропускаються,
а сесії й кеш використовують файли, черги — синхронний драйвер до подальшого налаштування.
