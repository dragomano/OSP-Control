# Локальный статический сайт

1. Перезапустите OSPanel, чтобы панель обнаружила __DOMAIN__.
2. Включите выбранный HTTP-модуль через OSPanel или OSP Control.
3. Откройте проект в браузере.
4. Редактируйте public/index.html и public/styles.css. Храните закрытые файлы вне public/.

Настройки проекта находятся в .osp/project.ini. Глобальные настройки модулей не изменены.
