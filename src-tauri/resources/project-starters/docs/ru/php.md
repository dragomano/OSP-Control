# Локальное PHP-приложение

1. Перезапустите OSPanel, чтобы панель обнаружила __DOMAIN__.
2. Включите выбранные модули HTTP и PHP.
3. Откройте проект в браузере, затем замените public/index.php своим приложением.
4. В командной строке OSPanel выполните `osp project __DOMAIN__`, чтобы активировать PHP-окружение проекта.

Публичный каталог — public/. Храните зависимости, реквизиты доступа и другие закрытые файлы вне него.
Настройки проекта находятся в .osp/project.ini. Пакеты не устанавливались.
