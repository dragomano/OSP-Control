# Заготовка проекта WordPress

Корень проекта — `{base_dir}`; OSPanel публикует только `public/`.

1. Сохраните настройки проекта и нажмите **__INSTALL_WORDPRESS__** на вкладке **__OVERVIEW__** проекта.
2. Установщик загрузит официальный стабильный ZIP-архив, проверит его контрольную сумму
   и распакует файлы WordPress непосредственно в `public/`, сохранив `.osp` и `.htaccess`.
3. Если при создании проекта была выбрана БД, заранее запустите соответствующий модуль
   MySQL/MariaDB. Указанному пользователю требуется право CREATE DATABASE.
   Существующие базы с выбранным именем не перезаписываются. Параметры подключения
   записываются в `public/wp-config.php`; если БД не выбрана, настройте её в мастере в браузере.
4. Перезапустите OSPanel и откройте сайт. В мастере WordPress задайте название сайта,
   учётную запись администратора и язык. Пароль администратора автоматически не создаётся.

Исходная заготовка сохраняется в `backups/project-starters`.
При ошибке загрузки или распаковки проект остаётся нетронутым. Дополнительные файлы
или правки публичной заглушки блокируют замену; в таком случае создайте новую заготовку
или установите приложение вручную. Созданная установщиком база сохраняется для повторной попытки.

Реквизиты БД хранятся локально в `.osp/database.json` (исключён из Git).
Не публикуйте этот файл и созданный `wp-config.php` при передаче проекта.
Не используйте корень проекта в качестве публичного каталога.
