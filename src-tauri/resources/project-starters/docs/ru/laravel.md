# Заготовка Laravel

Корень проекта — этот каталог, публичный каталог — public/.
Файл public/index.php первоначально показывает заглушку установки.

1. Включите выбранные модули HTTP и PHP в OSPanel.
2. В OSP Control откройте **__OVERVIEW__** проекта и нажмите **__INSTALL_LARAVEL__**.
3. Composer создаст приложение в отдельном временном каталоге. Только успешная установка
   переносится в корень проекта. Настройки .osp сохраняются.
   Дополнительные файлы проекта или правки заглушки нужно устранить перед установкой.
4. Исходная заготовка сохраняется в backups/project-starters/ внутри установки OSPanel.
   При ошибке Composer заготовка остаётся нетронутой; установку можно повторить.
5. Перезапустите OSPanel и откройте сайт. Активируйте консольное окружение командой
   `osp project __DOMAIN__`. Дополнительной папки вокруг каталога app/ Laravel нет.
6. Проверьте .env и параметры БД в соответствии с требованиями установленной версии.
   Установщик подготавливает выбранную базу, выполняет автообнаружение пакетов,
   создаёт ключ приложения и выполняет миграции. OSP Control не устанавливает и не запускает npm.
7. При необходимости после установки включите планировщик Laravel на вкладке **__TASKS__** проекта.

Установка использует выбранный PHP-модуль проекта (__PHP_ENGINE__) и его активный профиль
Composer в OSPanel. Убедитесь, что расширения PHP соответствуют требованиям Laravel.
Установщик откажется перезаписывать существующее приложение или изменённую заглушку.

https://laravel.com/docs/installation

## Настройка базы данных

SQLite создаёт `database/<selected-name>.sqlite` и выполняет миграции без отдельного
сервера БД. Для MySQL, MariaDB или PostgreSQL заранее запустите выбранный модуль OSPanel;
указанному пользователю необходимо право CREATE DATABASE. Установщик отказывается
использовать существующие базы и сохраняет созданную им базу для повторной попытки.
Реквизиты хранятся в `.osp/database.json` (исключён из Git) и в `.env` приложения.
Не публикуйте эти файлы. При выборе **__CONFIGURE_LATER__** миграции пропускаются,
а сессии и кеш используют файлы, очереди — синхронный драйвер до дальнейшей настройки.
