# Локальное Node.js-приложение

1. При необходимости установите выбранную версию Node.js через дополнение NVM в OSPanel.
   Перезапустите OSPanel и включите выбранный HTTP-модуль.
2. В командной строке OSPanel выполните `osp project __DOMAIN__ start`.
3. Откройте проект в браузере. HTTP-модуль перенаправляет запросы на 127.0.0.1:__PORT__.

Пример сервера использует встроенные модули Node.js и не требует установки пакетов npm.
Команда запуска — `node server.mjs`. Также можно выполнить `npm start` в окружении проекта.
Если порт __PORT__ занят, выберите другой порт backend и измените константу порта в server.mjs.

В заготовку включено необязательное задание однократного запуска; по умолчанию оно отключено.
Включите его на вкладке **__TASKS__** проекта, если приложение должно запускаться вместе с OSPanel.
При создании заготовки процессы автоматически не запускались.
