# Лакальны статычны сайт

1. Перазапусціце OSPanel, каб панэль выявіла __DOMAIN__.
2. Уключыце выбраны HTTP-модуль праз OSPanel або OSP Control.
3. Адкрыйце праект у браўзеры.
4. Рэдагуйце public/index.html і public/styles.css. Захоўвайце прыватныя файлы па-за public/.

Налады праекта знаходзяцца ў .osp/project.ini. Глабальныя налады модуляў не зменены.
