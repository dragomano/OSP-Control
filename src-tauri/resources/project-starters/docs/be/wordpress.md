# Загатоўка праекта WordPress

Корань праекта — `{base_dir}`; OSPanel публікуе толькі `public/`.

1. Захавайце налады праекта і націсніце **__INSTALL_WORDPRESS__** на ўкладцы **__OVERVIEW__** праекта.
2. Усталёўшчык спампуе афіцыйны стабільны ZIP-архіў, праверыць яго кантрольную суму
   і распакуе файлы WordPress непасрэдна ў `public/`, захаваўшы `.osp` і `.htaccess`.
3. Калі пры стварэнні праекта выбрана БД, загадзя запусціце адпаведны модуль
   MySQL/MariaDB. Указанаму карыстальніку патрэбна права CREATE DATABASE.
   Існуючыя базы з выбраным імем не перазапісваюцца. Параметры злучэння
   запісваюцца ў `public/wp-config.php`; калі БД не выбрана, наладзьце яе ў майстры ў браўзеры.
4. Перазапусціце OSPanel і адкрыйце сайт. У майстры WordPress задайце назву сайта,
   уліковы запіс адміністратара і мову. Пароль адміністратара аўтаматычна не ствараецца.

Пачатковая загатоўка захоўваецца ў `backups/project-starters`.
Пры памылцы спампоўвання або распакоўвання праект застаецца некранутым. Дадатковыя файлы
або змены публічнай заглушкі блакуюць замену; у такім выпадку стварыце новую загатоўку
або ўсталюйце праграму ўручную. Створаная ўсталёўшчыкам база захоўваецца для паўторнай спробы.

Рэквізіты БД захоўваюцца лакальна ў `.osp/database.json` (выключаны з Git).
Не публікуйце гэты файл і створаны `wp-config.php`, калі перадаяце праект.
Не выкарыстоўвайце корань праекта як публічны каталог.
