# Загатоўка Laravel

Корань праекта — гэты каталог, публічны каталог — public/.
Файл public/index.php спачатку паказвае заглушку ўсталявання.

1. Уключыце выбраныя модулі HTTP і PHP у OSPanel.
2. У OSP Control адкрыйце **__OVERVIEW__** праекта і націсніце **__INSTALL_LARAVEL__**.
3. Composer створыць праграму ў асобным часовым каталогу. Толькі паспяховае ўсталяванне
   пераносіцца ў корань праекта. Налады .osp захоўваюцца.
   Дадатковыя файлы праекта або змены заглушкі трэба вырашыць перад усталяваннем.
4. Пачатковая загатоўка захоўваецца ў backups/project-starters/ у каталогу OSPanel.
   Пры памылцы Composer загатоўка застаецца некранутай; усталяванне можна паўтарыць.
5. Перазапусціце OSPanel і адкрыйце сайт. Актывуйце кансольнае асяроддзе камандай
   `osp project __DOMAIN__`. Дадатковай папкі вакол каталога app/ Laravel няма.
6. Праверце .env і параметры БД паводле патрабаванняў усталяванай версіі.
   Усталёўшчык рыхтуе выбраную базу, выконвае аўтавыяўленне пакетаў,
   стварае ключ праграмы і выконвае міграцыі. OSP Control не ўсталёўвае і не запускае npm.
7. Пры патрэбе пасля ўсталявання ўключыце планавальнік Laravel на ўкладцы **__TASKS__** праекта.

Усталяванне выкарыстоўвае выбраны PHP-модуль праекта (__PHP_ENGINE__) і яго актыўны
профіль Composer у OSPanel. Упэўніцеся, што пашырэнні PHP адпавядаюць патрабаванням Laravel.
Усталёўшчык адмовіцца перазапісваць існуючую праграму або змененую заглушку.

https://laravel.com/docs/installation

## Наладжванне базы даных

SQLite стварае `database/<selected-name>.sqlite` і выконвае міграцыі без асобнага
сервера БД. Для MySQL, MariaDB або PostgreSQL загадзя запусціце выбраны модуль OSPanel;
указанаму карыстальніку патрэбна права CREATE DATABASE. Усталёўшчык адмаўляецца
выкарыстоўваць існуючыя базы і захоўвае створаную ім базу для паўторнай спробы.
Рэквізіты захоўваюцца ў `.osp/database.json` (выключаны з Git) і ў `.env` праграмы.
Не публікуйце гэтыя файлы. Калі выбрана **__CONFIGURE_LATER__**, міграцыі прапускаюцца,
а сеансы і кэш выкарыстоўваюць файлы, чэргі — сінхронны драйвер да далейшага наладжвання.
