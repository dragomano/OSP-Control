# Лакальная Node.js-праграма

1. Пры патрэбе ўсталюйце выбраную версію Node.js праз дадатак NVM у OSPanel.
   Перазапусціце OSPanel і ўключыце выбраны HTTP-модуль.
2. У камандным радку OSPanel выканайце `osp project __DOMAIN__ start`.
3. Адкрыйце праект у браўзеры. HTTP-модуль перанакіроўвае запыты на 127.0.0.1:__PORT__.

Прыклад сервера выкарыстоўвае ўбудаваныя модулі Node.js і не патрабуе ўсталявання пакетаў npm.
Каманда запуску — `node server.mjs`. Таксама можна выканаць `npm start` у асяроддзі праекта.
Калі порт __PORT__ заняты, выберыце іншы порт backend і змяніце канстанту порта ў server.mjs.

Загатоўка змяшчае неабавязковае заданне аднаразовага запуску, якое спачатку выключана.
Уключыце яго на ўкладцы **__TASKS__** праекта, калі праграма мае запускацца разам з OSPanel.
Пры стварэнні загатоўкі працэсы аўтаматычна не запускаліся.
