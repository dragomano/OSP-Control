# Лакальная PHP-праграма

1. Перазапусціце OSPanel, каб панэль выявіла __DOMAIN__.
2. Уключыце выбраныя модулі HTTP і PHP.
3. Адкрыйце праект у браўзеры, затым замяніце public/index.php сваёй праграмай.
4. У камандным радку OSPanel выканайце `osp project __DOMAIN__`, каб актываваць PHP-асяроддзе праекта.

Публічны каталог — public/. Захоўвайце залежнасці, рэквізіты доступу і іншыя прыватныя файлы па-за ім.
Налады праекта знаходзяцца ў .osp/project.ini. Пакеты не ўсталёўваліся.
